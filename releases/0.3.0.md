# Lovense Integrator 0.3.0

Screen mode reads semantic game events from a small color grid displayed by a compatible World of Warcraft addon. The addon is optional, distributed separately and not included in this application release.

- Preview the captured grid and recent game events in the Screen tab.
- Assign vibration, pulse or Stop to named events such as entering/leaving combat, incoming damage, healing and encounter outcomes.
- Configure device targets, intensity, duration, cooldown and window filters; import/export Screen assignments separately from keyboard and mouse rules.
- Adjust the capture position and physical cell size to match the addon. The default is an 8×8 grid with 4-pixel cells.
- Use English or Russian labels and the embedded Screen AI instructions.

Click **New assignment** to open a draft, then **Save assignment** to add it to the list. Start reading explicitly and enable rules when ready. Test signals appear only in the preview and never trigger effects. Losing the active game window or a live signal pauses armed Screen rules; recovery does not resume actions automatically.

Event availability depends on the game client and addon. Restricted health data is not decoded; general OCR and image/template recognition are not supported. Existing profiles and keyboard/mouse assignments are preserved.

Download **LovenseIntegratorApp-win-Setup.exe** or update through the app's Updates tab.
