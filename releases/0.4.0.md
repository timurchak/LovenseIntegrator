# Lovense Integrator 0.4.0

Configure a trigger, then attach an effect using the same editor in Keyboard, Mouse, Screen and Other events.

- All categories now share action choices, intensity, duration, device target, conditions and effect preview. Save assignment, Test effect and Delete assignment stay visible while scrolling.
- Reuse an effect with Copy saved effect. This copies the action, intensity, duration, pulse interval and device target into the current draft, preserving its trigger, name, conditions, cooldown, priority and identity. Copies are independent and must be saved; incompatible speed and continuous-wheel actions are excluded.
- Devices and Manual control have their own tabs. The permanent device sidebar is removed, giving trigger editing more room. Device selection stays synchronized across the two tabs.
- Jump directly to effect settings with Edit effect. Screen signal configuration and recent game events are grouped inside the trigger section.
- English and Russian interfaces use the same layout, with explicit units for numeric fields.

Existing profiles, assignment IDs, per-mode imports/exports and AI instructions remain supported. Editing, copying and previews do not activate devices. STOP ALL and Ctrl+Alt+F12 remain available, and rules start paused. The optional World of Warcraft addon remains separate and is not included in this release.

Download **LovenseIntegratorApp-win-Setup.exe** or update through the app's Updates tab.
