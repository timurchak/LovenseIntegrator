# Lovense Integrator 0.1.0

First Windows x64 installer release.

- Visual keyboard and mouse feedback modes, grouped assignments, exclusions and application filters.
- Manual controls, event rules, per-mode import/export and embedded AI instructions.
- Bluetooth with a standard adapter; isolated SDK worker and multiple-device connection handling.
- Self-contained installation: no separate .NET installation needed.
- GitHub auto-updates, background downloads and a restart button in the Updates tab.

Download **LovenseIntegratorApp-win-Setup.exe** and run it. The Bluetooth SDK is downloaded directly from Lovense and verified on the first Bluetooth connection; this first connection requires internet access. Demo and Local API modes do not need that download.

Existing profiles are preserved. Rules start paused after installation and updates. The installer is currently unsigned, so Windows may display a SmartScreen prompt. Screen recognition and Discord integration are not included.
