# Lovense Integrator 0.2.0

Choose **English** or **Русский** in **Settings → App language**, save, then restart when convenient. Main views, event descriptions, hints and app/update statuses follow your chosen language. The preference survives updates. Existing rule names, physical key codes and JSON formats are preserved; embedded AI instructions and low-level diagnostics remain English.

The installer now opens a step-by-step wizard instead of installing immediately.

- Choose the destination folder with Browse or by entering a path.
- Review the destination and planned changes before clicking Install.
- See extraction progress and the current installation step.
- Launch the app only if you select the checkbox on the final page.
- Existing installations are detected and upgraded in their current folder; profiles and rules are preserved.

To move an existing installation, uninstall the app through Windows Settings first, then run the wizard and choose a new folder. Uninstall keeps your saved profiles. GitHub auto-updates continue to work in the selected folder.

Download **LovenseIntegratorApp-win-Setup.exe**. The installer remains unsigned; Windows may display a SmartScreen prompt.
